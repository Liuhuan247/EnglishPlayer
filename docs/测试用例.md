# 测试用例（V1 验收基线）

来源：技术方案文档《测试用例导图（V1 验收基线）》。按里程碑分组，每条可直接作为开发完成后的验收清单；与《需求文档》功能清单对照执行。

## M1 播放核心

| 编号 | 用例 | 预期结果 |
|---|---|---|
| TC-101 | 本地视频播放（MP4 / MOV / MKV） | 正常播放，音画同步 |
| TC-102 | 本地音频播放（MP3 / M4A / WAV / FLAC） | 正常播放 |
| TC-103 | 倍速 0.5x 不变调 | 语速变慢、音调不变 |
| TC-104 | 倍速 2.0x 不变调 | 语速加快、音调不变 |
| TC-105 | 倍速 0.25 步进调节 | 0.5–2.0x 区间内连续可调 |
| TC-106 | 句边界精确 seek | 跳转后定位句首，误差小于 50ms |
| TC-107 | 断点续播 | 重启应用恢复上次媒体与位置 |
| TC-108 | 损坏文件 | 给出错误提示，不崩溃 |
| TC-109 | 不支持的格式 | 提示不支持，不崩溃 |
