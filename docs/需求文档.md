# 英语视频学习播放器（macOS）需求文档 V1.0

# 产品概述

## 产品定位

一款运行在 macOS 上的本地优先英语学习播放器：把本地或百度网盘里的英语视频、音频，变成可以逐句精听的学习材料。核心能力是**按句播放**——以字幕为句子边界，点哪句听哪句、单句循环、变速不变调的倍速播放。

## 目标用户与核心场景

  - **备考人群**：雅思、托福、考研英语，用美剧、纪录片、公开课做精听训练。
  - **看剧学英语**：用喜欢的剧集逐句跟读、查词，把娱乐变成学习。
  - **播客与有声书用户**：音频配 LRC 字幕逐句播放，通勤路上精听。
## 一句话价值

任何本地或网盘里的英语视频音频，打开就能逐句精听：点句播放、循环复读、变速听清、点击查词。

| 隐藏字幕盲听 | 一键隐藏字幕，先盲听再显示核对 | 包含 |
| 字幕偏移校正 | 字幕与声音不同步时，整体前移 / 后移（毫秒级） | 包含 |
| 断点记忆 | 记住每个文件的最后播放位置，重新打开续播 | 包含 |
| 播放列表 | 多文件连续播放，支持拖入文件批量加入 | 包含 |
| 快捷键体系 | 空格播放 / 暂停，← / → 上一句 / 下一句，↑ / ↓ 音量，数字键切换倍速 | 包含 |

# 百度网盘集成方案

## 目标与接入方式

用户授权登录百度网盘后，可浏览网盘内的视频 / 音频文件并播放，体验目标是与本地文件一致地使用按句播放、字幕、倍速全部能力。

## 已知约束与风险

  - **会员限制**：百度网盘官方客户端的倍速、原画播放是会员特权；第三方应用自行实现倍速可不受此限制，但获取播放 / 下载地址的速度和转码质量受账号等级影响，非会员大文件可能被限速。
  - **接口门槛**：需申请百度网盘开放平台接口权限，个人开发者申请难度与审核周期需实测验证。
  - **格式兼容**：网盘内非常见格式或超大文件（如几十 GB 的 MKV）在线转码播放可能失败，需要下载缓存兜底。
  - **可行性参考**：已有第三方播放器（如[迅雷影音](https://video.xunlei.com/pc)）于 2026 年 6 月起接入百度 / 阿里云盘实现在线播放并支持本地字幕，说明"开放接口直连网盘"路径可行，可作对标。
## 建议方案

| 方案 | 做法 | 状态与取舍 |
|---|---|---|
| 方案 A：在线流式播放 | 通过网盘开放接口获取文件播放地址，应用内直接播放，不落盘 | 后续迭代；体验最好，但受会员等级限速影响，接口权限待验证 |
| 方案 B：下载缓存播放 | 一键下载到应用缓存目录后播放，自动管理缓存空间 | V1 采用；开发量最小、体验最稳，需要本地存储空间 |

**建议**：V1 采用方案 B（下载缓存播放），开发量最小、体验最稳；方案 A（在线流式播放）留待后续迭代；两者共用同一播放链路，接入成本可控。

# 非功能需求

  - **性能**：1080P 视频流畅播放，字幕与声音同步无卡顿；支持 10GB 以上大文件。
  - **隐私**：网盘授权凭证仅保存在本机，不采集、不上传任何媒体内容与学习数据；本地优先。
  - **兼容**：目标 macOS 14 及以上（Sonoma），避免技术历史债务；优先适配 Apple Silicon。
  - **稳定性**：字幕文件解析容错，坏文件不导致崩溃；网盘断线可恢复。
# V1 范围界定与迭代路线

| 版本 | 范围 |
|---|---|
| V1（本版） | 本地播放＋网盘播放（下载缓存；在线流式后续迭代）＋字幕系统＋按句播放＋倍速＋欧陆词典查词＋句级波形＋断点记忆＋播放列表＋快捷键 |
| V2 | 无字幕 ASR 自动分句、生词本与收藏、跟读录音对比、学习时长统计、字幕词汇分析 |
| V3 | AI 整句翻译与讲解、网盘在线流式播放完善、云同步、iOS / iPadOS 多端 |

# 已确认决策

以下决策已由用户确认，构成 V1 范围基线。

| 决策点 | 结论 | 说明 |
|---|---|---|
| 网盘集成方式 | V1 采用下载缓存播放（方案 B） | 开发量最小；在线流式播放留待后续迭代 |
| 点击查词 | 纳入 V1，调用本地欧陆词典（Eudic） | 查词是"看英语视频"；经确认：通过欧陆词典 URL scheme 唤起，不内置词典、不使用系统词典 |
| 技术栈 | 先 macOS 原生（Swift） | 长期目标跨端，播放核心预留跨端接口，后续再评估跨平台方案 |
| 目标系统版本 | macOS 14 及以上（Sonoma） | 避免技术历史债务，优先适配 Apple Silicon |
| 音频字幕场景 | 支持 LRC 字幕逐句播放 | 音频配 LRC 后可逐句精听、倍速、循环 |
